### 📈 PC Hardware Price Intelligence
> A Python + SQL + ML pipeline tracking pricing trends across CPUs, GPUs, and other components.

| Layer | What it does |
|---|---|
| **Ingestion** | Python scrapers pulling hardware pricing across vendors |
| **Storage** | SQL schema designed for time-series queries on component prices |
| **Analysis** | ML models surfacing price patterns, deal signals, and trend shifts |
| **Goal** | Tell me *when* and *what* to buy — backed by data, not vibes |
